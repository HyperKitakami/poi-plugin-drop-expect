# poi-plugin-drop-expect

[poi](https://poi.moe/) 的掉落期望与资源预算计算器：给定点位的掉落率，算出「要刷多少次」「要花多少资源」「现有资源够不够」。

与只做记录的计数器不同，这个插件回答的是**决策问题**：同一艘船在几个点位都能掉时，哪个更省；资源只够刷 60 次时，成功率是多少。

## 功能

- **三种期望口径**，可随时切换
  - 单舰达成：某艘船至少出一艘
  - 集合 · 至少一艘：目标里任意一艘出现即可
  - 集合 · 全部收集：所有目标各至少一艘（精确 DP，不用近似公式）
- **目标期望可调**（50/80/90/99 或任意值），直接给出对应所需次数
- **资源预算**：油 / 弹 / 钢 / 铝 / 桶，补给与入渠分开填
- **反算**：现有资源最多能刷多少次、对应成功率多少、卡在哪项资源上
- **多点位对比**：同一艘船在多个点位的次数与消耗并列，可按次数 / 总油 / 掉落率排序
- **到达率修正**：撤退多时按实际到点率折算，不把「刷 76 次」当成「到点 76 次」
- **消耗可按史实估算**：接 Wheres My Fuel Gone 的历史出击记录，选定海域与时间段，算出平均消耗并一键填入
- **掉落率抓取**：一键从 kcwiki 掉落统计拉取，保留样本量与统计窗口；手填值优先，不被抓取覆盖
- 配置本地持久化，重启 poi 不丢

## 安装

在 poi 的插件设置里输入 `poi-plugin-drop-expect` 安装并启用；或手动：

```bash
cd "<poi 数据目录>/plugins"
npm install poi-plugin-drop-expect
```

poi 数据目录一般是：

- Windows：`%APPDATA%\poi`
- macOS：`~/Library/Application Support/poi`

## 使用

界面分三页：

1. **计算结果**：选目标期望（50/80/90/99 或任意值）与口径，看每艘目标舰在各点位的所需次数，以及刷完之后**还剩多少资源**（不足的项标红），并给出反算的「现有资源最多刷多少次、成功率多少」。
2. **期望曲线**：选一艘目标舰，看它在不同点位的曲线。纵轴可切换为次数或油/弹/钢/铝/桶，横轴是目标期望——能直接看出「再稳一点要多花多少」以及哪个点位更划算。
3. **点位与目标舰**：配置点位与目标舰、抓取掉落率、估算单次消耗。

配置步骤：

1. **加目标舰**：输入舰名或假名搜索，从 poi 自带的舰船列表里选。
2. **加点位**：填海域与格子（可从下拉选，也可直接手输，新活动图 fcd 未收录时手输即可）；活动图再选难度（甲/乙/丙/丁），并按需要选评价。
3. **填掉落率**：点「抓取掉落率」从 kcwiki 拉，或手动填。手填值优先，抓取不会覆盖（会在覆盖前询问）。
4. **填单次消耗**：补给（油/弹/铝）与入渠（油/钢）、桶分开填；也可以按海域 + 时间段从历史出击记录里统计。
5. 回到**计算结果**页看数值。

## 掉落率数据

数据来自 [kcwiki 掉落统计](https://db.kcwiki.cn/drop/)（poi-statistics）。

- `rate` 的分母是**该点位该评价的战斗结果总数**，已经包含「本次无掉落」的情形，因此可以直接当作「单次到达的掉落率」。
- 统计窗口是**滚动 30 天**，且站点缓存可能数周不更新。每个值都会带样本量与窗口，样本很少时建议手填。
- 接口只接受评价组合 `SAB / SA / S / A / B`；活动图才追加难度后缀。
- 抓取失败会区分四种情况：该图/难度无统计（404）、有该点位但无样本、网络失败、返回结构异常。

因为该接口没有 CORS 头，而 poi 的渲染进程没有关闭同源策略，抓取走的是 Node 的 `https`，不是 `fetch`。

## 数据存放

```
<poi 数据目录>/plugin-data/poi-plugin-drop-expect/state.json
```

写入走临时文件 + rename，坏文件会先退避为 `.bak` 再以空状态启动。

## 已知限制

- 不采集自己的出击记录，因此**到达率需要你自己估计**；单次消耗可以从 Wheres My Fuel Gone 的历史记录估算。
- 消耗统计只能到**海域**粒度（记录里没有格子），同一海域不同路线的消耗会混在一起；样本少于 10 次时会标注。
- 消耗统计不含支援与陆航（它们本身也是估算），界面会单独显示其数值供你自行加。
- 不区分敌舰编成；同一格不同编成掉落率不同时，聚合值会失真。
- 「全部收集」的目标数上限 12 艘，超过会退回近似估算并提示。
- 入渠油/钢是按入渠价折算的**估价**，不修船时实际支出更低。
- 掉落率低到需要上百万次时，结果会显示「—」而不是硬算。

## 开发

无需构建：poi 侧用 Babel 处理 `.es`，改完重新加载插件即可。

```bash
npm test    # 纯逻辑测试，不需要 poi，也不需要联网
```

测试覆盖概率三口径、边界与精度、成本与反算、报告汇总、存档读写与迁移、kcwiki 解析、i18n 键一致性。

```
calc/       纯函数：概率、成本、报告汇总（测试主战场）
services/   kcwiki 抓取与解析
redux/      状态与动作
store/      持久化、校验、写盘调度
views/      面板、结果表、点位编辑、图表
```
